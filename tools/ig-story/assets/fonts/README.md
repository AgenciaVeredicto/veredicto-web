# Fuentes

Poné acá el/los `.ttf` de una sans geométrica bold. El código busca en este orden:

1. `Montserrat-Bold.ttf` / `Montserrat-Medium.ttf`
2. `Poppins-Bold.ttf` / `Poppins-Medium.ttf`
3. `Inter-Bold.ttf` / `Inter-Medium.ttf`

Descarga (licencia SIL Open Font, uso libre):

- Montserrat: https://fonts.google.com/specimen/Montserrat
- Poppins: https://fonts.google.com/specimen/Poppins
- Inter: https://fonts.google.com/specimen/Inter

Si no hay ninguna, el generador cae a una fuente del sistema (DejaVu/Arial) como
último recurso, pero para el look "senior" usá Montserrat o Poppins Bold.

Los `.ttf` están ignorados por git (ver `.gitignore`).
